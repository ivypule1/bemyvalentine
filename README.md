# 💖 Valentine Web Project

A fun and interactive Valentine-themed web application built using HTML, CSS, and JavaScript. This project was created to practice front-end development fundamentals, DOM manipulation, and user interaction.

## 🌸 Features
- Interactive buttons and animations
- Dynamic text updates using JavaScript
- Responsive layout for mobile and desktop
- Clean and simple Valentine-themed design

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)

## 📚 What I Learned
- Structuring a project with HTML, CSS, and JavaScript
- Manipulating the DOM using JavaScript
- Handling user interactions and events
- Improving UI/UX through styling and layout

## ✨ Future Improvements
- Add more animations or effects
- Improve responsiveness
- Enhance accessibility
